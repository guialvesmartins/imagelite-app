# ImageLite App

Aplicação fullstack para gerenciar imagens com Spring Boot no backend e React/Next.js no frontend.

## Descrição

Projeto que demonstra integração entre Spring Boot (backend), React (frontend) e Next.js para criar uma aplicação web completa de gerenciamento de imagens, com suporte a Docker e PostgreSQL.

## Tecnologias

Spring Boot, React, Next.js, Tailwind CSS, PostgreSQL, Docker

## O que foi desenvolvido

Frontend com React e Next.js incluindo componentes estilizados com Tailwind CSS. Backend REST API com Spring Boot e banco de dados PostgreSQL. Aplicação containerizada e deploy com Docker.
